
# Hospital Management Dashboard \| Power BI

## Project Overview

The **Hospital Management Dashboard** is an interactive Power BI report
designed to present hospital-related information across multiple
business areas. It organizes the report into dedicated pages for an
overall overview, patients, doctors, hospital operations, and finance.

The dashboard helps users explore the available information through
visual reports, tables, cards, and slicers.

## Dashboard Pages

### 1. Home

-   Landing page for the report.
-   Provides navigation to the dashboard sections.

### 2. Overview

-   High-level summary of hospital information.
-   Includes visual analysis of spending by charge type.
-   Includes medicine-related analysis and appointment filtering.

### 3. Patient

-   Patient-focused report page.
-   Includes patient-related information and medicine analysis.
-   Shows spending by charge type and medicine sales quantity.

### 4. Doctor

-   Doctor-focused report page.
-   Includes doctor-related information and appointment details.
-   Provides appointment and rating filters, along with summary visuals
    and tables.

### 5. Hospital

-   Hospital operations page.
-   Includes doctor appointment information.
-   Includes patient test information and room occupancy analysis.

### 6. Finance

-   Finance-focused report page.
-   Includes month-wise medicine sales analysis.
-   Includes spending analysis by charge type and summary cards.

## Tools & Technologies

-   **Microsoft Power BI Desktop** -- Dashboard development and data

-   **Power Query** -- Data preparation, if used in the report workflow.
-   **DAX** -- Calculations and measures, if used in the report.

## Key Features

-   Multiple report pages organized by hospital function.
-   Interactive slicers and page navigation.
-   KPI/card-style summary visuals.
-   Charts, tables, and visual comparisons.
-   Patient, doctor, hospital operations, and finance views.

## How to View the Dashboard

1.  Download or clone this repository.
2.  Open `Hospital Dashboard.pbix` using Microsoft Power BI Desktop.
3.  Wait for the report to load.
4.  Navigate through the six report pages.
5.  Use the available slicers and filters to explore the report.
